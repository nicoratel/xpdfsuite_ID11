## 🎯 Quick Reference

### Command Reference
```bash
# Install package
pip install -e .

# Launch with default settings
xpdfsuite-h5-processor

# Launch on custom port
xpdfsuite-h5-processor --port 8503

# Launch without opening browser
xpdfsuite-h5-processor --headless

# Launch with network access
xpdfsuite-h5-processor --server-address 0.0.0.0

# Launch with Streamlit directly
streamlit run src/xpdfsuite_ID11/app_h5_processor.py
```

### File Format Reference
| File Type | Format | Required | Purpose |
|-----------|--------|----------|---------|
| Sample | H5/HDF5 | Yes | Main sample data |
| Reference | H5/HDF5 | Yes | Background data |
| PONI | PONI text | Yes | Calibration geometry |
| Mask | EDF | No | Bad pixel mask |
| Dark | EDF | No | Dark current |
| Flat | EDF | No | Flat-field response |
| Spline | Spline | No | Detector efficiency |

### Parameter Quick Reference
| Parameter | Tab | Range | Purpose |
|-----------|-----|-------|---------|
| Entry # | 1 | 0-N | HDF5 entry index |
| Frame # | 1 | 0-N or "mean" | Frame selection |
| Polarization | 1 | 0.0-1.0 | Correction factor |
| Q min/max | 1 | Å⁻¹ | Integration range |
| BGscale | 2 | 0.0-2.0 | Background scale |
| r min/max | 3 | Å | PDF range |
| Q_damp | 3 | 0.0-0.2 | Noise suppression |
